# The Social Company — website

Static website for The Social Company, a marketing and creative agency.

- `index.html` — the page (markup, styles and behaviour)
- `shared/content.js` — all copy in English and Greek
- `shared/core.js` — language switch, light/dark theme, footer funding banners
- `shared/base.css` — colours, fonts and shared styles
- `assets/banners/` — Republic of Cyprus and EU funding logos (light/dark, EN/EL)

No build step. Open `index.html` in a browser, or serve the folder with any static host.
